## 리뷰와 검증 범위

호출 대상 수와 순서, 큰 발언 분할, 프롬프트 여유와 Codex 문자 상한, 빈 입력과 빈 요약, 잘못된 정정 순서, 합성 인용 거절과 저장 안내를 검토했습니다. 부분 분석 응답에 해당 세션이 없는 경로는 오류로 처리하도록 보완했습니다. 앞의 세 조각만 고르는 동작으로 바꾸는 실험에서 후반 선택과 원문 연결 테스트 두 개가 실패했으며, 원래 구현을 복원한 뒤 전체 검증을 통과했습니다.

실제 사용자 대화나 비밀값을 외부 AI에 보내지 않았습니다. 로컬 테스트는 처리 범위와 원문 연결을 검증하며 실제 모델의 요약 품질, 공급자의 실제 토큰 계산과 할당량은 검증하지 않았습니다. 기존 중간 요약 경로의 마스킹 누락은 별도 범위로 남깁니다.

## 재검토에서 고친 문제

- [x] 제외한 원문도 근거 검사를 통과하는 문제를 실패 테스트로 재현했습니다. 선택한 원문 부분과 로컬 발언 순번을 보관하고, 같은 발언의 선택된 부분 안에 있는 인용만 허용합니다. 긴 발언의 제외된 부분, 다른 발언에 적힌 가짜 ID와 마스킹한 값도 검사했습니다.
- [x] 직접 분석에서 마스킹 뒤 입력 제한 검사를 건너뛰던 경로를 없앴습니다. 재시도 안내를 포함한 직접 입력으로 분석 방식을 정하고, 모든 최종 분석 입력을 마스킹 뒤 다시 검사합니다.
- [x] 누락 범위 표시가 없는 분석에서 세션이 빠진 응답을 성공으로 처리하는 문제를 실패 테스트로 재현하고 고쳤습니다.
- [x] 선택 범위 검사를 제거하는 실험에서 새 회귀 테스트가 실패하는 것을 확인하고 원래 검사를 복원했습니다.

후반 두 조각 선택, 원래 순서, 호출 상한과 누락 범위 표시는 유지했습니다. 새 검사는 인용이 전달 범위와 원문에 있는지 확인하며 의미의 정확성을 판정하지 않습니다.
