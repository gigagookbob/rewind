# 일일 노트 보존 구현 계획

1. 기존 전체 덮어쓰기의 데이터 손실을 합성 노트로 재현합니다. 자동 영역 비교와 파일 교체를 구현하고 `save_to_vault`에 연결합니다.
2. 같은 저장 경계에 진행 요약을 연결하고 명령의 저장 실패를 반환합니다. 순서 변경, 캐시 재저장, 표시 충돌과 파일 오류를 검증합니다.
3. 전체 오프라인 검사와 자체 리뷰를 마치고 부모 리뷰의 필요한 수정을 처리합니다. 검증한 변경만 로컬 커밋합니다.

- [ ] 사용자 메모, 앞머리와 표시 없는 기존 결과를 보존합니다.
- [ ] 분석과 요약을 반복하거나 순서를 바꿔도 각 자동 영역은 하나만 남습니다.
- [ ] 수동 수정과 잘못된 표시, 코드 상자를 보수적으로 처리합니다.
- [ ] 잠금과 임시 파일 교체, 읽기와 쓰기 오류를 검증합니다.
- [ ] 저장 실패가 명령과 백그라운드 완료로 이어지지 않는지 확인합니다.
- [ ] 빌드, Clippy, 전체 테스트, 포맷과 문서 검사를 통과합니다.
- [ ] 자체 리뷰, 변이 검사와 부모 리뷰 후 로컬 커밋과 5번 경계 인계를 마칩니다.
