# 여러 날 세션 구현 계획

1. Codex 과거 날짜 폴더 탐색을 고치고 당일 수집과 기존 중복 제거를 합성 로그로 확인합니다.
2. 공통 참고 선택 함수를 만들고 세 출처에 연결합니다. 당일 통계와 미래 제외를 확인합니다.
3. 근거의 참고 구분, 당일 사용자 요구와 프롬프트를 연결하고 긴 입력과 캐시의 호환성을 확인합니다.
4. 전체 오프라인 검사, 코드 리뷰와 필요한 수정을 마친 뒤 로컬 커밋과 부모 채팅 보고를 완료합니다.

- [ ] 과거 폴더와 한국 자정 경계, 당일 활동 없음, 미래 발언과 중복 수집을 검증합니다.
- [ ] 참고 선택 상한과 세 출처의 당일 통계, 파일과 줄 번호를 검증합니다.
- [ ] 과거 선택과 당일 정정, 긴 입력의 마지막 결론과 캐시 갱신을 검증합니다.
- [ ] 빌드, Clippy, 전체 테스트와 포맷 검사 후 리뷰합니다.
- [ ] 커밋과 재리뷰 결과, 남은 한계와 4번 파일 경계를 전달합니다.
