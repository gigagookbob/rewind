# 긴 세션 후반 보존 계획

기준 명세는 [SPEC-long-session.md](../SPEC-long-session.md)입니다. 기존 `plan.md`와 `todo.md`는 다른 작업의 기록이므로 보존합니다.

1. 조각 분할의 입력 상한을 먼저 고칩니다. 큰 발언과 한글 입력을 재현하는 실패 테스트를 추가하고, 역할과 ID를 포함한 길이와 원래 순서를 확인합니다.
2. 첫 조각과 마지막 두 조각을 선택하는 경로를 연결합니다. 조각 번호, 합성 요약 표시와 제외 범위를 함께 전달하고, 모델 응답 뒤에도 결과에 한계를 붙입니다. 공급자 실패는 부분 성공으로 바꾸지 않습니다.
3. 원문 근거와 저장 결과를 합성 데이터로 검사하고 한국어와 영어 프롬프트와 기존 문서를 갱신합니다. 전체 검증과 코드 리뷰 후 요청 범위만 로컬 커밋합니다.

모든 조각을 무제한 처리하면 호출 비용이 세션 길이에 비례해 늘어납니다. 끝의 발언 하나만 추가하면 결론의 맥락이 사라집니다. 기존 세 번의 상한과 연속된 후반 두 조각을 선택해 비용을 유지하고, 중간 누락은 명시합니다. 중간에만 있는 결정은 여전히 빠질 수 있으며 전체 분석이라고 표시하지 않습니다.
