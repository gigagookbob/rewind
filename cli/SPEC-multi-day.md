# 여러 날 이어지는 세션의 회고 명세

같은 세션을 다음 날 재개해도 당일 활동을 수집하고 이전 선택의 이유와 당일 변경을 연결합니다. 1번 근거 검사와 2번 긴 입력 처리를 유지합니다.

## 정책과 경계

- Codex는 대상 날짜의 UTC 종료일 이전 날짜 폴더를 모두 탐색합니다. 파일 수정 시각은 가져오거나 복사한 로그에서 믿을 수 없으므로 제외 기준으로 쓰지 않습니다. 실제 발언 시각으로 당일 활동을 판정합니다.
- Claude Code, Codex와 Antigravity는 같은 세션의 당일 시작 이전 사용자와 답변 중 최근 12개, 표시 문자를 포함해 합계 4,000자 이내를 참고 자료로 앞에 붙입니다. 발언 하나가 남은 몫보다 길면 끝부분만 남깁니다. 시각과 참고 표시, 실제 파일과 줄 번호를 보존합니다.
- 참고 자료는 별도 새 작업이 아닙니다. 결정, 학습과 정정은 당일 사용자 근거가 있어야 합니다. 모델은 당일 변경의 이유와 최종 상태를 우선하고 과거 결정을 새 결정으로 반복하지 않습니다. 의미와 철회 여부의 최종 판정은 모델 지시의 한계가 있습니다.
- 대상 날짜 이후 내용과 시각 없는 발언은 참고로 쓰지 않습니다. 세션 수, 활동 범위, 발언 수와 Claude 토큰 통계에는 당일 자료만 사용합니다.
- 긴 입력은 기존 첫 조각과 마지막 두 조각 정책을 유지합니다. 참고 맥락은 앞부분만 차지하며 당일 마지막 두 조각을 밀어내지 않습니다. 아주 작은 입력 한도에서는 앞부분의 당일 발언과 참고 자료가 생략될 수 있고 기존 부분 분석 표시가 남습니다.
- 캐시는 정책 버전과 실제 분석 메시지, 근거 위치와 시각을 해시해 비교합니다. 구 캐시는 읽을 수 있지만 새 수집 결과와 일치하지 않아 한 번 재분석합니다. 참고 자료 밖의 오래된 내용 변화는 재분석하지 않습니다.
- 전체 이력의 외부 전송, 새 데이터베이스, 자동화와 의존성을 추가하지 않습니다. 4번 노트 보존, 5번 모든 호출 마스킹과 6번 탐색 기능은 제외합니다.

## 코드와 확인

Rust 2024와 기존 Chrono, Serde를 사용합니다. 수집은 `src/parser/codex.rs`와 `src/sources/`, 참고 선택은 `src/analyzer/`, 검증은 각 모듈의 합성 로그 단위 테스트에 둡니다. 기존 `Result`와 `?` 방식으로 오류를 반환합니다.

```rust
let window = parser::local_date_to_utc_window(ctx.date)?;
```

`cargo test --offline --locked`, `cargo build --offline --locked`, `cargo clippy --offline --locked --all-targets -- -D warnings`, `cargo fmt --check`로 검증합니다. 앱 본체는 업데이트 확인과 알림 경로가 있으므로 실행하지 않습니다. 테스트 진입점은 해당 경로와 AI 공급자를 호출하지 않는지 확인하고 오프라인으로 실행합니다. 실제 모델의 의미 보존 품질은 검증하지 않습니다.

기존 `tasks/plan.md`와 `tasks/todo.md`에는 다른 작업의 미완료 항목이 있어 보존합니다. 이번 계획과 확인 항목은 `tasks/multi-day.md`에 둡니다.
